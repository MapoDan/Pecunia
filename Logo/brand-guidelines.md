# Pecunia — Brand Guidelines

This directory is reserved for the final visual identity.

## Assets

- `logo.png` — full application logo, to be supplied/finalized.
- `icon.png` — application icon, to be supplied/finalized.

## Usage guidance

The final visual system should define:

- primary logo;
- app icon;
- light/dark usage;
- minimum clear space;
- typography;
- primary/secondary colors;
- favicon/PWA icon variants;
- accessibility requirements.

The functional/UI specifications must not hard-code a visual identity before these assets are finalized.
